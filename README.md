# Portfolio Website

This is my personal portfolio website built to showcase my work, skills, and projects in a clean and interactive way. It reflects not just what I’ve built, but how I think, design, and solve problems as a developer.

## About the Project
The goal of this portfolio is to create a strong online presence and present my work in a visually appealing and user-friendly manner. I focused on smooth UI, responsive design, and modern web practices.

## Tech Stack
- React.js  
- Vite  
- Tailwind CSS + DaisyUI  
- Aceternity UI  
- JavaScript (ES6+)  

## Features
- Modern and responsive UI  
- Smooth animations and transitions  
- Clean and structured components  
- Project showcase section  
- Resume download option  

## Project Structure
The project is organized using reusable components and a scalable folder structure to maintain clean code and easy updates.

## Purpose
This portfolio is more than just a website — it’s a representation of my journey in web development, my learning curve, and my ability to build real-world applications.
